Nodes

Узлы делятся на группы, чтобы с ними было легче всего взаимодействовать:

  • INPUT — принимает все из ввода или из input директории.
  • OUTPUT — сохраняет и экспортирует результаты в output директорию.
  • PROPERTIES — выводит значения отдельного параметра для молекулы.
  • FILTERS — фильтрует поступающие объекты по признаку.
  • RDKIT — преобразования и анализ структур через RDKit.
  • SIMILARITY — оценивает сходство между молекулами.
  • NOTES — визуальные элементы для организации графа.
  • LOGIC — управление потоком данных.
  • MATH — математические операции с числами.

INPUT узлы

SMILESInputNode

Принимает: –
Выдаёт: MolData (RDKit_Mol), SMILES (String)
Параметры: поле ввода SMILES
Описание: вводите SMILES и получаете молекулу.

SDFIndexInputNode

Принимает: –
Выдаёт: MolData (RDKit_Mol), Count (Integer)
Параметры: имя файла (.sdf) в папке input/, кнопки ◀ ▶ для перебора
Описание: листает молекулы из SDF-файла и передаёт текущую дальше.

OUTPUT узлы

MolImageSaveNode

Принимает: MolData (RDKit_Mol)
Выдаёт: –
Параметры: Filename, Width, Height
Описание: сохраняет изображение молекулы в output/.

MolToSDFNode

Принимает: MolData (RDKit_Mol)
Выдаёт: –
Параметры: имя файла (.sdf) в папке output/
Описание: сохраняет молекулу в SDF-файл.

CSVLoggerNode

Принимает: MolData (RDKit_Mol)
Выдаёт: –
Параметры: имя файла (.csv) в папке output/, флаг Dedup
Описание: при каждом обновлении дописывает свойства молекулы в CSV. Не дублирует строки, если включён Dedup.

PrintNode

Принимает: Any
Выдаёт: –
Параметры: нет
Описание: показывает полученные данные внутри узла.

PROPERTIES узлы

Все свойства принимают MolData (RDKit_Mol) и выдают соответствующее значение. Параметров нет.

Узел Выходной пин Тип Описание
MolWeightNode MolWeight Float молекулярная масса
MolLogPNode LogP Float коэффициент распределения LogP
TPSANode TPSA Float топологическая полярная площадь
HBANode HBA Integer число акцепторов водорода
HBDNode HBD Integer число доноров водорода
HeavyAtomCountNode HeavyAtoms Integer количество тяжёлых атомов
NumAtomsNode NumAtoms Integer общее количество атомов
AromaticRingCountNode AromRings Integer количество ароматических колец
RingCountNode Rings Integer общее количество колец
RotatableBondsNode RotBonds Integer число вращающихся связей
MolecularFormulaNode Formula String молекулярная формула
QEDNode QED Float оценка лекарственного подобия
MolInspectorNode – (отображает внутри) сводка всех основных свойств

FILTER узлы

Все фильтры принимают MolData (RDKit_Mol) и выдают Pass (Bool) и MolOut (RDKit_Mol). В статической панели задаются минимальное/максимальное значение.

Узел Фильтруемый параметр
MolWeightFilterNode молекулярная масса
LogPFilterNode LogP
HeavyAtomFilterNode количество тяжёлых атомов
RotBondsFilterNode число вращающихся связей
RuleOfFiveFilterNode комплексное правило Липински (MW, LogP, HBD, HBA)

RDKIT узлы

SaltRemoverNode

Принимает: MolData (RDKit_Mol)
Выдаёт: MolData (RDKit_Mol)
Параметры: нет
Описание: удаляет соли, оставляя самый крупный органический фрагмент.

MolTo3DNode

Принимает: MolData (RDKit_Mol)
Выдаёт: MolData 3D (RDKit_Mol)
Параметры: нет
Описание: генерирует 3D-координаты (ETKDG) и выдаёт молекулу с конформером.

MolToInChINode

Принимает: MolData (RDKit_Mol)
Выдаёт: InChI (String)
Параметры: нет
Описание: конвертирует молекулу в стандартный InChI.

SMILESCanonicalizerNode

Принимает: SMILES (String)
Выдаёт: Canonical SMILES (String)
Параметры: нет
Описание: преобразует любой SMILES в каноническую форму.

SMILESValidatorNode

Принимает: SMILES (String)
Выдаёт: Valid (Bool)
Параметры: нет
Описание: проверяет, является ли строка корректным SMILES.

SIMILARITY узлы

TanimotoSimilarityNode

Принимает: MolData A (RDKit_Mol), MolData B (RDKit_Mol)
Выдаёт: Tanimoto (Float)
Параметры: нет
Описание: вычисляет коэффициент Танимото по Morgan-отпечаткам (радиус 2, 2048 бит).

LOGIC узлы

IfNode

Принимает: MolData (RDKit_Mol), Pass (Bool)
Выдаёт: True (MolData), False (MolData)
Параметры: нет
Описание: если Pass=True, молекула появляется на выходе True, иначе на выходе False.

BoolAndNode

Принимает: A (Bool), B (Bool)
Выдаёт: A AND B (Bool)
Параметры: нет
Описание: логическое И.

BoolOrNode

Принимает: A (Bool), B (Bool)
Выдаёт: A OR B (Bool)
Параметры: нет
Описание: логическое ИЛИ.

MATH узлы

MathNode

Принимает: A (Float), B (Float)
Выдаёт: Result (Float)
Параметры: выбор операции (+, -, , /)
Описание:* выполняет арифметическую операцию над двумя числами.

NOTES узлы

StickyNoteNode

Принимает: –
Выдаёт: –
Параметры: многострочный текст
Описание: текстовая заметка с автоматическим переносом строк. Сохраняется в проекте.
